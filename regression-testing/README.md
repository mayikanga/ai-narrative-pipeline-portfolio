# 多案例回归测试与成本分析

使用 10 篇固定案例，对文本和生图流水线的阶段 01～06 做逐阶段测试，记录结构验收、质量评分、请求数、Token、缓存、耗时和估算费用。

## 测试方式

- 真实模型适配器：验证实际 API 行为；
- 回放适配器：复用已保存响应，不产生新的模型费用；
- 代码验收：检查编号、覆盖、Schema、参考图和比例；
- 人工抽查：阅读问题案例和哨兵案例，避免把“命令成功”误判为质量通过；
- 稳定基线：只有全量通过、路径和哈希可追溯、质量与成本对比完成后才冻结。
