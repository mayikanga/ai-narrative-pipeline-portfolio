# 文本流水线

负责将中文人生故事转换为可继续处理的结构化叙事数据：语义块、原子句段、连续场景、人物设定、地点设定、主题物件和场景生图提示词。

## 核心流程

1. 语义分块；
2. 场景初拆；
3. 场景检验与定点修复；
4. 生成人物、地点和主题物件设定；
5. 生成场景提示词；
6. 对提示词做结构、语义、连续性、中文和比例验收。

## 技术特点

- Node.js 多阶段流水线；
- DeepSeek API 结构化调用；
- JSON Schema 与代码验收结合；
- 阶段级 checkpoint 和中断恢复；
- 稳定索引、原文哈希和失败项定点修复。

详细说明见[开发者指南](./developer-guide.md)。
